# Memory Game

A simple neon memory game built with HTML, CSS, and JavaScript. Watch the lights, remember the sequence, and repeat it to reach the next level.

## Download & Play

1. Download the `index.html` file from this repository to your computer.
2. Double-click the downloaded file to open it in your web browser.
3. Choose your speed and click **LET'S PLAY**.

That's it! No installation, account, or internet connection is needed after downloading.

> Download the HTML file itself, rather than saving the GitHub page. If you download the repository as a ZIP, extract it first, then open `index.html`.

## How to Play

- Watch the order in which the pads light up.
- When **YOUR TURN** appears, click the pads in the same order.
- Each cleared level adds one more step and earns **10 points**.
- A wrong pad ends the run. Click **TRY AGAIN** to start a new one.

## Controls

- **Mouse / Touch:** Select a pad.
- **Number keys 1–9:** Select the matching numbered pad.
- **CHILL / FLOW / TURBO:** Choose the playback speed before starting.
- **Sound icon:** Turn sound on or off. Sound is enabled by default and starts after your first interaction.

Your best cleared level is saved separately for each speed in the same browser when local storage is available.
